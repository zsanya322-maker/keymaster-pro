## 📝 О проекте

**KeyMaster Pro** — мощное настольное приложение для Windows, построенное вокруг одной идеи: **всё есть правило**. Вместо того чтобы переключаться между отдельными экранами для переназначения, макросов, слоёв и текстовых расширений, вы собираете каждое правило в едином **Конструкторе правил**:

```
[ ТРИГГЕР ]  +  [ УСЛОВИЯ ]  →  [ ДЕЙСТВИЯ ]
```

Нажатие клавиши, клик мыши, набранная аббревиатура или tap-hold запускает правило. Необязательные условия (активное окно, активный слой) определяют, сработает ли оно. Затем выполняется одно или несколько действий — переназначение клавиши, запуск макроса, привязка окна, управление медиа и многое другое.

Построено на **Rust + Tauri v2 + React 19**. Работает на уровне ОС через `SetWindowsHookEx`, перехватывая и обрабатывая ввод в реальном времени, с **полным отсутствием логирования** и минимальным потреблением памяти (~23 МБ ОЗУ, <1% ЦП).

> Ищете **бесплатную, открытую альтернативу** AutoHotkey, PowerToys Keyboard Manager или Key Manager? Вы её нашли.

## ✨ Возможности

Всё живёт внутри **Конструктора правил** — единого модального окна, где вы собираете правило из трёх частей. Больше не нужно переключаться между разрозненными экранами.

### 🎯 Триггеры (что запускает правило)
- **Key Down / Key Up** — любая клавиша или комбинация
- **Mouse Down / Mouse Up** — левая, правая, средняя, X1, X2 кнопки
- **Tap-Hold** — короткое нажатие запускает одно действие, удержание — другое (home-row mods, в стиле kanata)
- **Typed Text** — наберите аббревиатуру для запуска расширения

### ⚡ Действия (что происходит при срабатывании правила)
| Категория | Действия |
|---|---|
| **Переназначение** | Remap Key, Remap Mouse Button |
| **Ввод** | Type Text, Run Macro (записанные шаги клавиш + мыши с задержками) |
| **Слои** | Toggle Layer, Hold Layer (пока клавиша удерживается) |
| **Система** | Громкость (mute / up / down), Media Key (play / next / prev / stop), Sleep, Monitor Off |
| **Окна** | Snap left / right / center, Minimize, Maximize, Close, Focus Process Window |
| **Запуск** | Launch Application |

### 🧩 Условия (необязательно — когда правило должно сработать)
- **Layer Active** — правило срабатывает только пока включен определённый слой
- **Window Match** — правило срабатывает только когда активное окно совпадает с именем процесса и/или заголовком окна
- **Virtual Desktop** — правило привязано к конкретному виртуальному рабочему столу

### 🔄 Профили приложений
Группируйте правила в **профили**, которые автоматически переключаются по активному окну приложения. Разные правила для редактора, браузера и игр — автоматически.

### 🔥 Слои (в стиле QMK)
Переключайте или удерживайте слой, чтобы полностью изменить поведение клавиш — одна и та же клавиша может делать разное в разных слоях. Слои — полноценные сущности: переключайте их из любого правила или удерживайте клавишу, чтобы слой был активен только во время нажатия.

### 🚀 Двухпроцессная архитектура
Лёгкий фоновый **демон** (Rust) обрабатывает низкоуровневые хуки ввода и выполнение правил, а **GUI** (React) остаётся отзывчивым. Закройте интерфейс — переназначения продолжат работать.

### Дополнительно
| Функция | Описание |
|---------|----------|
| 🧙 **Мастер онбординга** | Встроенные стартовые примеры для новичков — рабочее переназначение за секунды |
| 📊 **Мониторинг в реальном времени** | ЦП, ОЗУ, задержка и счётчик нажатий в строке состояния |
| 🔔 **Автообновление** | Обновление внутри приложения через Tauri updater (или `winget upgrade`) |

## 📥 Скачать

### Вариант A: WinGet (рекомендуется)

Установите KeyMaster Pro одной командой на Windows 10/11:

```bash
winget install KeyMasterPro.KeyMasterPro
```

- Автоматическое обновление: `winget upgrade KeyMasterPro.KeyMasterPro`
- Не нужно ничего скачивать вручную — WinGet всё сделает сам

> Требуется [WinGet](https://github.com/microsoft/winget-cli) (предустановлен на Windows 10 1709+ и Windows 11).

### Вариант B: Установщик

➡️ Перейдите в [**Releases**](https://github.com/zsanya322-maker/keymaster-pro/releases) и скачайте `KeyMaster-Pro_x.x.x_x64-setup.exe`

- **Не нужны** зависимости — просто скачайте и запустите
- WebView2 Runtime предустановлен на Windows 10/11 (автоскачивание при отсутствии)
- Установщик поддерживает **автообновление** через GitHub

### Вариант C: Портативная версия

Скоро — портативная версия `.zip` планируется в будущих релизах.

## 🛠️ Сборка из исходников

### Предварительные требования

1. **Node.js** 18+ и **pnpm** (`npm i -g pnpm`)
2. **Rust** 1.70+ ([rustup.rs](https://rustup.rs))
3. **Visual Studio Build Tools** — рабочая нагрузка: `Microsoft.VisualStudio.Workload.VCTools`
   - Скачать: https://visualstudio.microsoft.com/visual-cpp-build-tools/

### Шаги

```bash
# Клонировать репозиторий
git clone https://github.com/zsanya322-maker/keymaster-pro.git
cd keymaster-pro

# Установить зависимости фронтенда
pnpm install

# Запуск в режиме разработки
pnpm tauri dev

# Сборка бинарника (.exe)
pnpm tauri build
```

Готовый установщик появится в `src-tauri/target/release/bundle/nsis/`.

## 🛡️ Безопасность и ложные срабатывания

Поскольку KeyMaster Pro использует низкоуровневые Win32 API для перехвата и переназначения ввода (`SetWindowsHookEx`), некоторые антивирусы могут ошибочно помечать его как кейлоггер или инструмент инъекции ввода. **Это ложное срабатывание.**

**Наши гарантии безопасности:**

1. **Отсутствие логирования ввода** — Приложение **не сохраняет, не записывает и не передаёт** ваши нажатия клавиш. Вся обработка происходит в реальном времени, в оперативной памяти.
2. **Офлайн-first** — Все конфигурации хранятся локально в формате JSON в `%APPDATA%`. Никакого облака, никакой телеметрии.
3. **Отсутствие скрытой сетевой активности** — Единственный сетевой запрос — проверка обновлений через HTTPS на GitHub.

*Если Windows Defender или антивирус блокирует приложение, добавьте `KeyMasterPro.exe` в список исключений.*
